# IDE neovim config on Ubuntu

### Install

## Install [rustup](https://rustup.rs)
## Install [treesitter-cli](https://github.com/tree-sitter/tree-sitter/blob/master/crates/cli/README.md)

## Install neovim
```sh
sudo add-apt-repository ppa:neovim-ppa/unstable
sudo apt update
sudo apt install\
    software-properties-common\
    git curl wget\
    gzip tar unzip\
    ripgrep fd-find\
    xclip\
    gcc g++ make clang\
    python3-full python3-venv python3-pynvim\
    nodejs node-typescript npm\
    neovim
```


## Clone this repo
```
git clone git@github.com:vuongkienthanh/nvim-configs-linux.git ~/.config/nvim
```
